# text

The `text` brick outputs translated text via `wrap_text()`. See
[Translating Text](zzwrap/Translating Text.md) in zzwrap for PHP
usage, parameters, and sentence lists.

## Examples

```
%%% text Hello world %%% 
%%% text Your life is what your thoughts make it. %%% 
%%% text "We found %d items" item_count %%% 
%%% text "Fr" context=weekdays %%%
```
